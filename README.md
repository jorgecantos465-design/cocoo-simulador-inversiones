# Simulador de Inversiones

Web app simple de Cocoo para evaluar el impacto estimado de una inversión en la caja antes de tomar la decisión.

## Alcance

- Sin login
- Sin base de datos
- Sin pagos
- Sin descargas
- Cálculos en frontend

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm test
npm run build
```
