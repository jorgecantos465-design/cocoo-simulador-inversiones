# Skill: Frontend UI - simulador inversiones

## Objetivo
Presentar capital, flujo, recupero, salida y escenarios de manera legible y responsive.

## Cuando usarla
Usala para cards, graficos, formularios de inversion, estados y layout.

## Pasos obligatorios
- Revisar patrones existentes en `Simulator.tsx`.
- Mantener metricas clave visibles.
- Probar montos grandes y textos largos.
- No ocultar escenarios negativos.

## Checklist antes de modificar
- El cambio no altera calculos.
- Se contemplan financiacion y salida.
- Viewports principales considerados.

## Checklist antes de finalizar
- Build exitoso.
- Resultados no se superponen.
- Grafico y cards se leen en mobile.

## Errores que debe evitar
- Presentar resultado positivo sin contexto de caja.
- Reducir legibilidad por exceso visual.
- Romper navegacion por pasos.

## Comandos de verificacion
- `npm run build`
- `npm run dev`

## Formato de reporte final
- Pantallas tocadas.
- Estados verificados.
- Viewports.
- Riesgos visuales.
