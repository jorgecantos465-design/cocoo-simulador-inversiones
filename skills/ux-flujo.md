# Skill: UX y flujo - simulador inversiones

## Objetivo
Guiar al usuario para entender inversion inicial, flujo mensual, salida, recupero y sensibilidad.

## Cuando usarla
Usala para pasos, ayudas, resultados, escenarios y lenguaje de riesgo.

## Pasos obligatorios
- Diferenciar caja personal de resultado de inversion.
- Explicar recupero y salida estimada.
- Mostrar escenarios antes de conclusiones fuertes.
- Mantener tono informativo, no recomendador.

## Checklist antes de modificar
- Punto de confusion identificado.
- El cambio conserva contexto de riesgo.
- No pide datos que el usuario no puede estimar.

## Checklist antes de finalizar
- Flujo completo probado.
- El usuario entiende recupero y resultado.
- Escenarios dificil/favorable/custom son claros.

## Errores que debe evitar
- Usar jerga de ROI sin explicacion.
- Ocultar que una inversion puede mejorar patrimonio y tensionar caja.
- Tratar salida estimada como garantizada.

## Comandos de verificacion
- `npm run dev`
- `npm run build`

## Formato de reporte final
- Flujo revisado.
- Copy/labels cambiados.
- Riesgos de interpretacion.
- Validacion manual.
